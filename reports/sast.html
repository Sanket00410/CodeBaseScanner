critical User input reaches a dynamically built SQL query

DEMO-SAST-01 · SQL-INJECTION-EXAMPLE · open
Sources: codesentinelx, semgrep
orders/api.py:42

User input reaches a dynamically built SQL query. Linked source, observation and deployment records are retained in this investigation.

codesentinelx evidence
user_id = request.args.get("id")
query = f"SELECT * FROM users WHERE id = {user_id}"
cursor.execute(query)
semgrep evidence
user_id = request.args.get("id")
query = f"SELECT * FROM users WHERE id = {user_id}"
cursor.execute(query)

Fix: Use the parameter-binding API for your actual database driver. The placeholder syntax depends on that driver. Add a regression test and reassess the same code.

Why vulnerable?
Untrusted input is included in SQL structure rather than passed as a bound value.
